# Codex Operations

Repository for Codex operational notes, diagnostics, and runbooks for the Hermes environment.

## Current Scope

- Hermes VPS diagnostics
- Docker / Compose repair notes
- Agent runtime runbooks
- Human validation records before risky actions

## Safety Rules

- Do not commit tokens, private keys, or full `.env` files.
- Do not store Discord, Telegram, GitHub, OpenRouter, or provider secrets.
- Keep production actions documented with date, command intent, and verification result.
